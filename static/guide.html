送信方法（curl）

パソコンのコマンドラインから、curl でデータを送る方法です。M5StickC をつなぐ前の動作確認にも使えます。

あなたのチャネル

下の欄に入れた値が、このページのコマンドにすべて反映されます。

1回だけ送る

d1〜d8 に数値を入れて送ります。使わない項目は書かなくてかまいません。

成功すると {"status": "ok", "count": 1} と表示され、グラフのページ（チャネルのページ）にデータが追加されます。

一定間隔で送り続ける

30秒ごとに乱数を送ります。グラフが動く様子を確かめたいときに使います。止めるときは Ctrl + C を押します。

届いたデータを確認する

新しい順に5件を取り出します。n= の数字で件数を変えられます。

送れるデータ

項目内容
writeKeyチャネルのライトキー（必須）
d1 〜 d8数値データ。最大8種類まで。23.5 のような数値でも "23.5" のような文字列でも受け付けます
cmntコメント（文字列）。グラフで確認できます
created測定した時刻（省略するとサーバーが受け取った時刻）。"2026-10-27 10:00:00"（日本時間）や UNIX 時刻（秒・ミリ秒）で指定します
lat, lng緯度・経度（使う場合のみ）

送信の間隔について

同じチャネルへの送信は、前回の受信から一定時間あける必要があります。

うまくいかないとき

返ってきた結果原因と直し方
200 {"status": "ok", ...}成功です
403 「writeKey が違います」ライトキーが間違っています。マイページか配布されたキーカードで確認してください
404 「チャネル … は存在しません」チャネルIDが間違っています
429 「… 秒たっていないため受け付けませんでした」前回の送信から間隔が短すぎます。表示された秒数だけ待ってから送ってください
400 「JSON の形式が正しくありません」{ } の中の書き方が崩れています。コマンドプロンプトでは " の前に \ が必要です（上の例をそのままコピーしてください）
「SSL certificate problem」などの証明書エラーパソコンの日付・時刻がずれていないか確認してください。古い curl で起きる場合は、アドレスを http:// に変えても送れます
301 / 302（転送）アドレスの書き間違いがないか確認してください（/api/v2/channels/…/data まで正しく入っているか）
curl が見つからないWindows 10 以降は標準で入っています。コマンドプロンプトでは curl.exe と入力してください
